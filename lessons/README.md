# Lessons

These notes follow the build phases of harness-lab. Read the lesson, then the code it names, in the order it gives. Do the exercises before starting the next phase.

| Phase | Lesson | What you build |
|---|---|---|
| 1 | [The minimal loop](01-minimal-loop.md) | One provider, a bash tool, stop conditions, a session log, a one-shot CLI |
| 2 | Tools and guardrails | read, write, edit, and bash, with a workspace boundary and an approval gate |
| 3 | Layers, events, streaming, and a local server | Token streaming, an event bus, a TUI or print frontend, a second provider, a local server |
| 4 | Sessions, AGENTS.md, and compaction | Resume, project instructions, token accounting, auto-compaction |
| 5 | Subagents, skills, and MCP | Spawned child agents, `SKILL.md`, lifecycle hooks, an optional MCP client |
| 6 | Production hardening | Sandboxing, retries, headless runs, tracing, evals |
| 7 | Custom bots | Per-bot persona, memory, tool scopes, cron or webhook triggers, more than one channel |

Phases 2–7 are listed so you can see the road. Their lessons are not written yet.
